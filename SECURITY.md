# Security Policy

## Supported Versions

This project only supports the version published under the `latest` Git tag.

| Version | Supported |
| --- | --- |
| `latest` tag | Yes |
| `HEAD` / default branch snapshots | No |
| Older tags, commits, or release archives | No |

Please reproduce security issues against the `latest` tag before reporting them. If an issue only affects `HEAD`, an older tag, or any other untagged commit, it is outside the supported security scope.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.

Report vulnerabilities privately through GitHub's repository security advisory workflow:

1. Open the repository on GitHub.
2. Go to **Security** → **Advisories**.
3. Select **Report a vulnerability** or **New draft security advisory**.
4. Include reproduction steps, impact, affected versions, and any suggested fix if available.

We will review reports for the supported `latest` tag and coordinate remediation through the GitHub Security Advisory before public disclosure.
