# Security Policy

## Supported Versions

This project only supports the version published as the latest GitHub Release.

| Version | Supported |
| --- | --- |
| Latest GitHub Release | Yes |
| `HEAD` / default branch snapshots | No |
| Older releases, tags, commits, or release archives | No |

Please reproduce security issues against the latest GitHub Release before reporting them. If an issue only affects `HEAD`, an older release, or any other untagged commit, it is outside the supported security scope.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.

Report vulnerabilities privately through the [nhm7/sap_api_mcp security advisory form](https://github.com/nhm7/sap_api_mcp/security/advisories/new).

We will review reports for the supported latest GitHub Release and coordinate remediation through the GitHub Security Advisory before public disclosure.
